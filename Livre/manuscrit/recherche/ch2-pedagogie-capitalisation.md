## A. Définitions précises et distinctions sémantiques

### 1. La capitalisation : définition fondamentale

La **retraite par capitalisation** repose sur un mécanisme simple mais puissant : transformer des **cotisations présentes en capital productif** qui génère un rendement dans le temps.

Le cycle est le suivant :

1. **Accumulation** : pendant la carrière (40 ans), un travailleur ou une entreprise verse régulièrement des cotisations (ex. : 10 % du salaire) sur un compte dédié.
2. **Investissement** : ces cotisations sont immédiatement investies dans un **portefeuille diversifié** (actions 60%, obligations 30%, immobilier 10% typiquement).
3. **Rendement** : le portefeuille génère un rendement annuel (ex. : 6-7% brut long terme), qui s'ajoute au capital.
4. **Effet composé** : chaque année, les nouveaux rendements sont eux-mêmes réinvestis — c'est l'**effet boule de neige**.
5. **Désaccumulation** : à la retraite (65 ans), le capital accumulé est converti en **rente mensuelle fixe** ou en **retraits progressifs**.

**Différence fondamentale avec la répartition** : en répartition, la cotisation du travailleur d'aujourd'hui paye immédiatement la retraite d'un pensionné actuel. En capitalisation, la cotisation du travailleur finance sa **propre retraite future**.

Source : [Retraite par capitalisation — Wikipédia](https://fr.wikipedia.org/wiki/Retraite_par_capitalisation)

### 2. Capitalisation vs répartition : l'opposition fondamentale

Pour bien comprendre le projet politique du livre, il faut clarifier cette distinction.

| Dimension | Répartition (France actuellement) | Capitalisation |
|-----------|-----------------------------------|-----------------|
| **Flux financier** | Cotisations actuelles → Retraites actuelles | Cotisations → Portefeuille → Retraites futures |
| **Horizon temporel** | Court terme (1-2 ans) | Long terme (40+ ans) |
| **Rendement** | Aucun (transfert direct) | Rendement du marché (6-7% long terme) |
| **Risque** | Démographique (ratio actifs/retraités) | Marché (volatilité actions) |
| **Propriété du capital** | État (pas de compte individuel) | Individu ou fonds de pension |
| **Exemple** | CNAV, CNAVPL (France) | Pensions Québec, GPFG Norvège |

**Bruno Palier** (*Réformer les retraites*, Sciences Po 2021, p. ??) [À VÉRIFIER : page exacte] note que cette opposition est moins absolue en pratique : la plupart des systèmes réels combinent une part répartition (solidarité) et une part capitalisation (accumulation individuelle). Mais le **ratio** entre les deux change tout : France aujourd'hui est ~99% répartition, Suède ~30% capitalisation, Pays-Bas ~70% capitalisation.

### 3. Capitalisation vs assurance-vie individuelle : deux mondes différents

C'est une confusion courante. L'assurance-vie existe en France depuis 1960 et génère 1 178 Md€ d'encours fin 2024 (source : [ACPR N°170 — Le marché de l'assurance-vie en 2024](https://acpr.banque-france.fr/fr/publications-et-statistiques/publications/ndeg-170-le-marche-de-lassurance-vie-en-2024)). Mais ce n'est **pas un système de capitalisation structurel** pour la retraite.

#### Assurance-vie (fonds euros classiques)

- **Caractère** : *Volontaire*, optionnel, individuel
- **Horizon** : Variable (5-30 ans selon le contrat)
- **Rendement 2024** : En moyenne **2,63 % brut** pour les contrats individuels (source : [ACPR — Revalorisation 2024 des contrats](https://acpr.banque-france.fr/system/files/2025-08/20250804_AS175_Revalorisation_contrats_assurance_vie_2024.pdf))
- **Garantie** : Capital garanti (« ratchet effect » : gains définitifs chaque année)
- **Risque** : Très faible (obligations, immobilier sécurisé)
- **Rente/sortie** : Libre (capital, rente optionnelle, retrait flexible)
- **Fiscalité** : Intéressante (30% flat tax ou prélèvements sociaux selon durée)

#### Capitalisation structurelle (fonds de pension, GPFG, CDPQ)

- **Caractère** : *Obligatoire*, systémique, collectif
- **Horizon** : Strictement 40+ ans (carrière entière)
- **Rendement 2024** :
  - CDPQ (Québec) : 9,4 % / 6,2 % sur 5 ans / 7,1 % sur 10 ans (source : [CDPQ 2024 Annual Report](https://www.cdpq.com/en/performance/annual-reports/2024))
  - GPFG (Norvège) : 13,1 % / 6,3 % long terme (1998-2024) (source : [NBIM Annual Report 2024](https://www.nbim.no/en/news-and-insights/reports/2024/annual-report-2024/))
- **Garantie** : Aucune (rendement de marché, positif ou négatif)
- **Risque** : Modéré à élevé (actions 60-70%, obligations 25-30%)
- **Rente/sortie** : Stricte (rente à 65 ans, non prélevable avant)
- **Fiscalité** : Simplifiée (aucune imposition individuelle, fonds transparent)

**Conclusion** : l'assurance-vie est un **produit d'épargne secondaire volontaire**, pas un pilier de retraite systémique.

### 4. Capitalisation vs PER (Plan d'Épargne Retraite) : faux semblant

Le PER, créé en 2019 en France, est souvent présenté comme une réponse à la demande de capitalisation. C'est une confusion majeure.

**Données PER (France, T3 2024)** :
- Encours : **119 Md€** (source : [Bercy — Communiqué février 2025](https://presse.economie.gouv.fr/epargne-retraite-deploiement-du-per-plus-de-11-millions-de-titulaires-et-pres-de-119-milliards-dencours-au-troisieme-trimestre-2024/))
- Titulaires : 11 M
- Par type :
  - PER individuel : 68,1 Md€
  - PER collectif d'entreprise : 27,2 Md€
  - PER obligatoire : 23,6 Md€

**Pourquoi le PER n'est pas une vraie capitalisation** :

1. **Volontarisme** : l'adhésion reste largement volontaire (sauf PER obligatoire en entreprise)
2. **Pas de structuration systémique** : 11 M titulaires sur 30 M actifs français = 37%. Comparé à Pays-Bas (90%), Suède (99%), Danemark (85%), c'est résiduel.
3. **Rendement faible** : PER moyen ~3-4% / an, inférieur aux grands fonds de pension européens
4. **Fléchage insuffisant** : PER permet des versements volontaires à faible cadence ; pas d'obligation patronale structurelle
5. **Sortie flexible** : contrairement aux fonds de pension, le PER peut être prélevé avant 60 ans sous certaines conditions (achat résidence, handicap...). C'est une **épargne retraite**, pas un **régime de retraite**

Source OCDE & AFG : [OECD Pensions Outlook 2024](https://www.oecd.org/en/publications/oecd-pensions-outlook-2024_51510909-en.html)

Le PER est un **produit d'épargne retraite complémentaire**, équivalent au Roth IRA (USA) ou au SIPP (Australie), pas un système obligatoire comme la Superannuation australienne ou les fonds de pension néerlandais.

### 5. Capitalisation vs livret réglementé (Livret A, LDD, LEP)

| Critère | Livret réglementé | Capitalisation |
|---------|-------------------|-----------------|
| **Rendement 2025** | 2,5 % à 4,5 % fixe/an | 6-7% long terme actions |
| **Plafond** | Oui (ex. : 22 500 € Livret A) | Illimité |
| **Liquidité** | Immédiate (jour pour jour) | Retraite (65 ans) |
| **Risque** | Zéro (État français) | Modéré (marché) |
| **Fiscalité** | Exonérée | Impôt sur revenus sauf PEA |
| **Usage** | Épargne de précaution | Retraite obligatoire |

Les livrets sont des **outils de trésorerie court-moyen terme**, pas une réponse au financement des retraites long terme. Leur rendement réel (net d'inflation) est actuellement **négatif** (2,5% - 2,5% inflation = 0%).

Sources : [ACPR fonds euros 2024](https://acpr.banque-france.fr/fr/publications-et-statistiques/publications/ndeg-170-le-marche-de-lassurance-vie-en-2024)

### 6. Capitalisation vs bourse individuelle : ce n'est pas « jouer ses cotisations »

Confusion très fréquente auprès du grand public : « capitalisation = placer ses cotisations directement en bourse = risqué ».

**Réalité** :

1. **Diversification obligatoire** : Un fonds de pension (CDPQ, GPFG, ABP) **ne place pas** les cotisations brutes en actions seules. Structure typique :
   - 60-70% actions (diversifiées mondialement)
   - 25-35% obligations (gouvernementales, corporates)
   - 5-10% immobilier, infrastructures, alternatives
   - 0-2% liquidités

2. **Gestion professionnelle** : Des équipes d'investisseurs professionnels (pas des day-traders) gèrent ces portefeuilles selon des règles strictes. Exemple : NBIM (Norvège, GPFG) emploie ~1 000 professionnels.

3. **Rendement net** : Le fonds absorbe les frais de gestion (0,2-0,5% / an typiquement) et verse un rendement **net** aux pensionnés.

4. **Long termisme** : Un fonds de pension en capitalisation n'a **pas intérêt** à trader court terme. Son horizon est 40-50 ans. Cela crée une **stabilité** contrairement aux marchés spéculatifs.

**Rendement long terme réel** (actions mondiales depuis 1900) : **5,2 % par an** selon UBS / Dimson-Marsh-Staunton (source : [Global Investment Returns Yearbook 2025](https://www.ubs.com/global/en/investment-bank/insights-and-data/2025/global-investment-returns-yearbook-2025/)) — ce qui dépasse largement l'inflation (~2,5%) et les obligations (~1,7%).

## C. La mécanique du rendement composé

### 1. Définition et illustration

L'**effet composé** est la réinvestissement automatique des rendements. Si vous investissez EUR 10 000 à 6% / an sur 40 ans :

- **Année 1** : EUR 10 000 → rendement EUR 600 → capital = EUR 10 600
- **Année 2** : EUR 10 600 → rendement EUR 636 → capital = EUR 11 236
- **...** (le rendement crée lui-même du rendement)
- **Année 40** : Capital = **EUR 102 857**

C'est une **multiplication par ~10** due uniquement au fait que les EUR 600 de rendement année 1 ont eux-mêmes généré du rendement pendant 39 ans.

**Formula** : Capital final = Capital initial × (1 + taux)^années  
Ici : 10 000 × (1,06)^40 = 102 857

### 2. Comparaison avec d'autres horizons

| Durée | Capital initial | Taux | Capital final | Gain total |
|-------|-----------------|------|-----------------|-----------|
| **10 ans** | EUR 10 000 | 6% | EUR 17 908 | +79% |
| **20 ans** | EUR 10 000 | 6% | EUR 32 071 | +221% |
| **30 ans** | EUR 10 000 | 6% | EUR 57 434 | +474% |
| **40 ans** | EUR 10 000 | 6% | EUR 102 857 | +928% |

C'est pourquoi la capitalisation exige une **carrière entière** (40 ans) pour fonctionner. À 10 ans, l'effet composé n'est que ~80%.

### 3. Le argument « r > g » de Piketty appliqué pédagogiquement

**Thomas Piketty** (*Le Capital au XXIe siècle*, Seuil 2013, formulation centrale de l'ouvrage, voir notamment pp. 53-55 pour l'introduction du concept) pose que « quand r > g — c'est-à-dire quand le rendement du capital dépasse le taux de croissance économique — le capital s'accumule plus vite que ne croît l'économie ». [page exacte à vérifier dans l'édition papier]

En pédagogie retraite, cela signifie :

- **r** = rendement moyen du portefeuille capitalisé = 6-7% / an (actions long terme)
- **g** = croissance économique moyenne = 2-3% / an (long terme OCDE)
- **Écart** = 3-4 points / an → c'est l'avantage de la capitalisation

Si vous cotisez EUR 5 000 / an pendant 40 ans en capitalisation à r=6% :
- Cotisations totales = EUR 200 000
- Capital final = EUR 773 000 (dont EUR 573 000 de rendement)

Si ces mêmes EUR 5 000 / an restaient en répartition (0% rendement) :
- Capital final = EUR 200 000 (cotisations seules)

**L'écart (EUR 573 000) est l'effet Piketty appliqué**. C'est aussi pourquoi Piketty s'inquiète : si les riches captent tout le r, les inégalités explosent. En capitalisation systémique (France), tout actif capturerait ce r, d'où son intérêt égalitaire.

**Important** : Cette application est *pédagogique*, pas politique. Piketty lui-même plaide pour la **redistribution** du capital, pas pour la capitalisation retraite. Mais mathématiquement, r > g explique pourquoi la capitalisation génère plus de retraite que la répartition.

### 4. Sur la fausse citation Einstein

La citation « l'intérêt composé est la 8ème merveille du monde » est **probablement apocryphe**. Il n'existe aucune trace vérifiée d'Einstein disant ou écrivant cela. Elle circule largement en finance (blogs, livres), mais sans source primaire authentique.

Cela ne nie pas le phénomène : l'effet composé est réellement puissant mathématiquement. Mais **ne pas l'attribuer à Einstein** dans le livre. Dire plutôt : « L'effet composé est souvent appelé la huitième merveille du monde par les financiers, bien que cette citation soit apocryphiquement attribuée à Einstein. »

Source : [Mintos — Taux d'intérêt composé : la 8ème merveille du monde selon Einstein](https://www.mintos.com/blog/taux-interet-compose-8eme-merveille-du-monde-selon-einstein/) (note : Mintos reconnaît l'incertitude)

## D. Cotisations en répartition vs capitalisation : le chemin de l'euro

### 1. En répartition (France 2024)

Vous cotisez **EUR 100** en tant que salarié (part salaire + part patronale EUR 42).

**Destination immédiate** :
- CNAV collecte EUR 142
- EUR 142 sont **versés la même année** aux pensionnés actuels qui touchent leur retraite
- Aucune accumulation, aucun investissement
- Vous n'avez aucune créance « sauvegardée » — juste un droit futur à retraite (implicite, non-financé d'avance)

**Risque** : Si les actifs diminuent (démographie, chômage), le système doit :
- Augmenter les cotisations, ou
- Réduire les retraites, ou
- Puiser dans les impôts

**Rendement** : Zéro. EUR 142 cotisés = EUR 142 dépensés, rien ne s'accumule.

### 2. En capitalisation (modèle CDPQ, GPFG, ABP)

Vous cotisez **EUR 100** en tant que salarié.

**Destination** :
- La caisse de pension collecte EUR 142
- EUR 142 sont **investis immédiatement** dans :
  - Indices MSCI World (50 EUR : actions mondiales)
  - Obligations gouvernementales (40 EUR : sécurité)
  - Immobilier (25 EUR : diversification)
  - Liquidités (27 EUR)
- Ce portefeuille de EUR 142 **vous appartient** (droit de propriété formalisé)
- **Année 1** : rendement ~6% = EUR 8,5 → nouveau capital = EUR 150,5
- **Année 2** : rendement 6% = EUR 9,03 → capital = EUR 159,5
- Après 40 ans : capital ~EUR 900-1000

**Risque** : Risque de marché (les actions peuvent baisser une année). Mais sur 40 ans, historiquement zéro risque (actions n'ont jamais eu de rendement négatif sur 40 ans depuis 1900).

**Rendement** : 6-7% / an composé. L'accumulation est **propriété de l'assuré**.

### 3. Comparaison stylisée

| Dimension | Répartition | Capitalisation |
|-----------|------------|-----------------|
| **Flux** | EUR 142 → Retraités actuels | EUR 142 → Portefeuille |
| **Accumulation** | Zéro | EUR 900-1000 après 40 ans |
| **Propriété** | L'État (droit implicite) | L'individu/le fonds (droit explicite) |
| **Risque** | Démographique | Marché |
| **Transparence** | Opaque (pas de compte) | Transparent (relevé annuel) |
| **Héritage** | Aucun | Possible (capital résiduel) |
| **Équité intergénérationnelle** | Génération X paie Gen Y ; Gen Y paiera Gen Z... | Chacun paie sa retraite |

## E. Rendements réels et observation empirique long terme

### 1. Données historiques (UBS / Dimson-Marsh-Staunton)

Le rapport [Global Investment Returns Yearbook 2025](https://www.ubs.com/global/en/investment-bank/insights-and-data/2025/global-investment-returns-yearbook-2025/) couvre 125 ans d'histoire (1900-2025) dans 35 pays. Voici les **rendements réels annualisés** (net d'inflation) :

| Classe d'actif | Rendement réel long terme |
|---|---|
| **Actions mondiales** | 5,2% / an |
| **Obligations gouvernementales** | 1,7% / an |
| **Bons du Trésor court terme** | 0,5% / an |
| **Inflation moyenne** | ~2,5% / an (période entière) |

Ces chiffres sont **après** déflation par l'inflation historique, donc c'est le vrai rendement de pouvoir d'achat.

Pour la France spécifiquement (non isolé dans le rapport) : données bancaires suggèrent ~5% réel actions, ~1,5% obligations (années 2010-2024).

Source : [Global Investment Returns Yearbook 2024 — UBS Global](https://www.ubs.com/global/en/investment-bank/insights-and-data/2024/global-investment-returns-yearbook.html)

### 3. Rendements en France : assurance-vie vs fonds euros

Pour comparaison (ce qui existe déjà en France) :

- **Fonds euros en assurance-vie** : 2,63 % brut 2024 (source : ACPR)
- **Actions en assurance-vie (UC)** : Variable (~8-12% 2024)
- **Livrets A/LDD** : 2,5-4,5 % fixe (réglementé)

**Le PER moyen** : ~3-4% / an (mix euros/actions)

**L'écart** : Un fonds de pension type (60% actions + 40% obligations) aurait généré ~7-8% en 2024, vs ~2,6% pour les fonds euros « sûrs ». C'est **l'écart de rendement** qui explique pourquoi la capitalisation structurelle changerait les retraites.
