## 📊 DONNÉES CLÉS — COPIER-COLLER READY

### Flexicurité (Danemark)
- Chômage : **4-5%** (vs 7,2% France 2026)
- Allocation durée : **24 mois** (vs 36 France)
- Formation : **Obligatoire** (vs zéro France)

### Hartz (Allemagne, 2003-2005)
- Chômage avant : **11%** → Après : **5,5%** (7 ans)
- Créations d'emplois : **2,5 millions**
- **Caveat** : miniJobs augmentés (7,4 M fin 2010)

### Consolidation fiscale (Canada, 1994-1999)
- Réduction déficit : **-30 Md$** → **+14,3 Md$ surplus** en 4 ans
- Ratio cuts/augmentations : **7:1** (dépenses prioritaires)
- Croissance subséquente : **3,3%/an** (1997-2007)

### Retraite NDC (Suède, 1994)
- Durabilité : **Oui** (balancing automatique)
- Rendement : **Transparence**
- Lien contribution-rente : **Clair**

### Retraite AFP (Chili, 1981)
- Rendement annuel : **10%** (moyen)
- Remplacement retraite : **20-30%** (vs 70% promis)
- **Problème** : Couverture 50%, rentes faibles

### Nucléaire (Corée SK)
- Coût : **3.571 $/kW** (vs 7.931 France)
- Délai construction : **56 mois** (vs 72+ France)
- **Secret** : Standardisation + apprentissage 45 ans

### Nucléaire (France Messmer, 1974-1989)
- Réacteurs construits : **56**
- Délai moyen : **6 ans/réacteur**
- Résultat décarbonation : **75% électricité** (toujours valide 2026)

### Fusion communes
- **Danemark** (2007) : 271 → 98 communes | Économies : 9% nominal, **0 services**
- **Japon** (1999-2010) : 3.232 → 1.727 communes | Coûts : **+0-18%**

### Immigration points-based (Canada)
- Output potentiel : **+2,5%** (2023-24)
- PIB per capita : **BAISSE**
- Housing crisis : **OUI** (Toronto, Vancouver, Montreal)

### Zoning (Houston)
- Construction taux : **14× villes comparables**
- Affordability : **À risque** récemment (climat, demand)

### Vouchers école (Suède, 1992)
- Écoles indépendantes : 38 → **396** (×10)
- Gains académiques : **ZÉRO**
- Ségrégation : **AUGMENTATION**

## ⚠️ PIÈGES PRINCIPAUX

1. **Flat tax pure** — Inapplicable France (budget trop haut)
2. **Fusion communes** — Jamais d'économies réelles (Danemark + Japon preuves)
3. **Retraite Chili-style** — Rentes faibles (20-30% vs 70% promis)
4. **Vouchers école** — Zéro gains académiques + ségrégation
5. **Immigration volumes élevés** — Housing crisis (Canada 2024 disaster)
6. **Austerité procyclique** — Réduction dépenses dans croissance faible = récession (Irlande 2008)
7. **Déréglementation logement seule** — Houston affordability "at risk" sans transports/taxes

## 📞 FAQ RAPIDES

**Q: Faut-il vraiment supprimer les communes?**
A: Non. Danemark 271→98 + Japon 3232→1727 = zéro économies services. Mutualisation (EPCI) mieux.

**Q: Flat tax à 20% possible France?**
A: Non. Dépense 56% PIB. Réduction niches fiscales (30 Md€) + taux progressif simplifié mieux.

**Q: Flexicurité danoise applicabile?**
A: Oui, version légère. MAIS requiert politiques actives obligatoires (clé succès Danemark).

**Q: Retraite par points viable?**
A: Oui, Suède NDC modèle (France 2023 Macron = quasi-NDC déjà).

**Q: Nucléaire réalisable 2027-2035?**
A: Oui. SMR + EPR2 standardisés (imiter Corée SK coûts). Flamanville finir d'abord.

**Q: Immigration points viable politiquement?**
A: Oui si **volumes limités** (15K élites/an). Canada 400K/an = disaster 2024.

**Q: Austerité possible 2027-2032?**
A: Prudence. Canada 1994 ✓ (contexte croissance 3%+). Irlande 2008 ✗ (contexte récession). France 2026 = risque procyclique. Consolidation progressive (5 ans) mieux que brutale.
