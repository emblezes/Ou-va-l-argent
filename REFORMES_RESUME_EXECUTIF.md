# RÉSUMÉ EXÉCUTIF — Réformes Libérales Internationales pour France 2027

**Audience** : Candidats, think tanks, experts économie politique

**Format** : 1 page synthèse + tableaux chiffres clés

## RÉFORMES QUI MARCHENT (données robustes)

### 1. FLEXICURITÉ + POLITIQUES ACTIVES (Danemark)
- **Données** : Chômage bas (4-5%), durée courte, rotation élevée
- **Modèle** : Licenciement facile + allocation 90% salaire 24 mois + formation obligatoire
- **Facteur clé** : Politiques actives OBLIGATOIRES (pas juste aide)
- **Pour France** : Réduire durée allocation (36→24 mois) + stage obligatoire
- **Coût politique** : TRÈS ÉLEVÉ (syndicats)

### 2. RÉDUCTIONS CHÔMAGE STRUCTUREL (Allemagne, Hartz 2003-2005)
- **Données** : 11% → 5,5% chômage en 7 ans ; créations 2,5 M postes
- **Réforme** : Assouplissement licenciement (Hartz I-III) + fusion chômage/aide (Hartz IV)
- **Caveat** : Augmentation emplois précaires (miniJobs, contrats courts)
- **Pour France** : Imiter assouplissement SANS dérive précariat (protections salaire minimum)

### 3. CONSOLIDATION FISCALE (Canada 1994-1999)
- **Données** : -30 Md$ dépenses (7:1 spending/tax ratio) → équilibre → +3,3%/an croissance
- **Contexte** : Économie croissante (vs France stagnante 2026)
- **Pour France** : Réduction progressive dépenses 2028-2032 (austerity-procyclique RISQUE)

### 4. SIMPLIFICATION FISCALE (Slovaquie 2004, Estonie 1994)
- **Données** : 19% flat (Slovakia) → croissance 6-8% ; 26% flat (Estonie) → 11,7% en 1997
- **Caveat majeur** : Contexte post-transition (rattrapage économique automatique)
- **Pour France** : Réduction exemptions (30 Md€/an) plutôt que taux baisse
- **Modèle viable** : Taux progressif simple (3 tranches) + base large

### 5. RETRAITE NOTIONNELLE (Suède, NDC)
- **Données** : Système durable, balancing automatique, transparent
- **Avantage** : Lien contribution-rente clair, pas privatisation
- **Pour France** : Estendre système points Macron (déjà quasi-NDC)

### 6. NUCLÉAIRE STANDARDISÉ (Corée SK, France Messmer)
- **Données SK** : 3.571 $/kW, 56 mois délai (vs France 7.931 $/kW, 72+ mois)
- **Données France** : 56 réacteurs 15 ans (1974-1989), décarbonation réussie
- **Pour France** : SMR + EPR2 standardisés (imiter Corée apprentissage coûts)

## PROGRAMME RÉALISTE FRANCE 2027-2032

### ANNÉE 1 (2027)
- **Nucléaire** : Décision 14 EPR2 + 4 SMR, budget 2027-2028
- **Travail** : Projet loi licenciement assouplissement
- **CPF** : Extension santé complémentaire

### ANNÉES 2-3 (2028-2029)
- **Allocation chômage** : Durée -6 mois, formations obligatoires
- **Budget** : Réduction -5 Md€ dépenses (gels salaires)
- **Logement** : COS +20%, supprimer obligation % social

### ANNÉES 4-5 (2030-2032)
- **Impôts** : IS 25%→22% (via CIR suppression)
- **Éducation** : Autonomie budget + choix école encadré
- **Retraite** : Finaliser NDC points-based

### RÉSULTATS 2032
- Déficit 2,5% (vs 3,5% 2026)
- Chômage 6,0% (vs 7,2% 2026)
- Croissance 1,8%/an (vs 0,9% 2026)

## CHIFFRES CLÉS PAR RÉFORME

### Flexicurité Danemark
- Chômage : 4-5% (vs 7,2% France)
- Allocation durée : 24 mois (vs 36 mois France)
- Formation obligatoire : YES (vs zéro France)

### Hartz Allemagne
- Chômage pré-réforme : 11% (2005)
- Chômage post-réforme : 5,5% (2012)
- Créations emplois : 2,5 M (8 ans)
- **Caveat** : miniJobs 7,4 M (précariat)

### Canada consolidation fiscale
- Déficit avant : -30 Md$ (1995-96)
- Déficit après : +14,3 Md$ surplus (1999-00)
- Période : 4 ans
- Croissance subséquente : 3,3%/an (1997-2007)

### Slovaquie flat tax
- Taux : 19% (IR/IS/TVA)
- Croissance avant : 3,4%/an (6 ans)
- Croissance après : 6% (2005), 8,3% (2006)
- **Caveat** : Adhésion UE 2004 (confondant)

### France nucléaire Messmer
- Réacteurs : 56 construits (1974-1989)
- Délai : 6 ans/réacteur
- Décarbonation : 75% électricité (toujours valide)
- Coûts : Doublés (1970-1997) mais compétitifs vs US

### Corée SK nucléaire
- Coût : 3.571 $/kW (vs 5.833 US, 7.931 France)
- Délai : 56 mois (vs 72+ France)
- Standardisation : 2 réacteurs/3 ans (45 ans)
- Résultat : Courbe apprentissage continue

## MESSAGES-CLÉS POLITIQUES

### ✓ What works
- "Flexicurité à la danoise" (sécurité sans chômage infini)
- "Nucléaire standardisé" (Corée SK modèle coûts)
- "Consolidation budget ciblée" (dépenses vs impôts, Canada modèle)

### ✗ What fails
- "Fusion communes" (jamais économies réelles)
- "Retraite capitalisation" (rentes faibles, Chili preuve)
- "Vouchers école" (zéro gains, ségrégation, Suède échec)

### ⚠️ Contingent on context
- **Flat tax** : Fonctionne post-transition (Estonie), pas économie mature (France)
- **Immigration points** : Fonctionne élites, pas volumes élevés (Canada 2020s disaster)
- **Austerité** : Fonctionne croissance (Canada), échoue récession (Irlande 2008)
